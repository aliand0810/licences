# Licences

Système de licences pour mes logiciels.

- `licence_pro.html` — générateur / tableau de bord (ouvrir, configurer token + secret)
- `licences.json` — base des licences (uniquement des hash, aucune clé en clair)
- `licence_check.js` — à coller en haut du script de chaque logiciel (adapter `PRODUIT`)

Intégration : `<script src="https://aliand0810.github.io/licences/licence_check.js"></script>` après avoir défini le produit dans le fichier.
