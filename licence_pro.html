🔗 Connexion des applications (Firebase)

Enregistre ici l'objet firebaseConfig et le Client ID Google de chaque logiciel. Une fois la licence activée, l'application se relie toute seule à son projet Firebase : plus besoin de coller la configuration sur chaque appareil.

☁️ Client ID Google par défaut

Utilisé pour toutes les licences de ce logiciel dont le champ « Client ID Google » est vide. Le changer ici met à jour tous tes clients à leur prochaine ouverture.

🆕 Inscriptions en ligne — compte administrateur de l'application

Ton identifiant et ton mot de passe administrateur dans le logiciel (ex. Mon Planning Pro). Ils permettent d'activer le compte d'un nouveau client dès que tu acceptes son inscription. Enregistrés seulement sur cet appareil, jamais sur GitHub.

📲 Transfert vers un autre appareil

Pour avoir exactement les mêmes clés sur ton téléphone et ton ordinateur, transfère tes réglages (token, secret maître, Firebase) depuis l'appareil de référence au lieu de les retaper. Le code est chiffré avec un mot de passe de transfert.

🔒 Sécurité

Les réglages se verrouillent automatiquement quand tu quittes cet onglet ou après 5 minutes d'inactivité.
